## Eval-harness client contract (from §0 parity caveat + PLAN §2)

Every chat call, both engines:

- `"chat_template_kwargs": {"reasoning_strength": "low"}` (Glimmer is a reasoning model;
  without it the model can burn the whole budget thinking and return `content: null`)
- generous `max_tokens`; score `message.content` only; log `message.reasoning` separately
- capability scores: temp 1.0 / top-p 0.95 / top-k 64; greedy (temp 0) **only** for
  deterministic parity checks

## Versioning policy

- torch/flash-attn/hf libs: never ad-hoc installed; changes go through `pyproject.toml`
  (bounded ranges, never torch/flash-attn) + `docker compose build dev` + `verify-env.sh`.
- No DeepSpeed/FSDP/Axolotl/LLaMA-Factory/NeMo (PLAN §1) — revisit only on concrete need.
- SGLang: not installed (branch-based support); only if a concrete need emerges.

## Portability (RTX 5090 target box, from CONTRIBUTING §8)

Same files, multi-arch images: rerun `scripts/detect-host-gpu.sh` (writes `x86_64` + that
host's driver), rebuild both images (arch-specific layers), `CUDA_ARCHES=120` alone is fine.
